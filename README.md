# 张灿个人作品集

视觉设计师 / AI 设计师 / 品牌设计师个人作品集，使用 React + Vite 构建。

## 本地运行

当前电脑已准备好依赖，可直接双击 `start.cmd`，或在终端中运行：

```bat
start.cmd
```

也可以在已安装 Node.js 的终端中使用标准命令：

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可。

## 构建预览

```bash
npm run build
npm run preview
```

如需一键启动已经构建好的版本：

```bat
start.cmd -Preview
```

## 内容与素材

- 个人资料、联系方式与经历整理自 `张灿简历.pdf`
- 项目图片、人物照与视频位于 `public/assets`
- 页面内容集中维护在 `src/App.jsx` 的 `CONTACT`、`PROJECTS`、`CAPABILITIES` 和 `EXPERIENCES` 数据中
